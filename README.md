SmartSpend AI

Smart Financial Assistant for Small Businesses

About the Project

SmartSpend AI is a web-based financial assistant designed for small businesses. It brings essential financial management tools together in one place.

Features

1. Business Dashboard – Displays total business income, total expenses, and net profit or loss.

2. Transaction Management – Allows users to add business income and expenses and view transaction history.

3. Cash Flow Forecast – Estimates monthly income, expenses, and closing balance using recorded transactions.

4. GST Invoice Generator – Generates GST invoices using business, customer, and product details.

5. EMI Calculator – Calculates estimated monthly loan payments based on loan amount, interest rate, and duration.

6. Smart Business Tips – Provides tips based on recorded transactions.

Technologies Used

- HTML
- CSS
- JavaScript

AI Models and APIs

This prototype uses rule-based calculations for its financial features. No external AI model or API is currently integrated.

How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Start using the available features.
